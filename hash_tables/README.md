# C - Hash tables

This project covers the implementation and usage of hash tables in C, focusing on:
- What a hash function is and what makes a good one.
- How hash tables work and how to handle collisions via chaining.
- The advantages, drawbacks, and common use cases of hash tables.

## Tasks
* **0. 0-hash_table_create.c**: Writes a function that creates a hash table of a given size.
