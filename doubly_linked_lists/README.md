# C - Doubly linked lists

This project is part of the Holberton School low-level programming curriculum. It focuses on understanding and implementing data structures using **doubly linked lists** in the C programming language.

## Learning Objectives
* How to use doubly linked lists.
* Understanding structures and pointers in C.
* Writing clean code that passes the Betty linter.

## Requirements Met
* Compiled on Ubuntu 20.04 LTS using `gcc`.
* Checked with `betty-style.pl` and `betty-doc.pl`.
* No global variables are used.
* All header files are include-guarded.
